脉脉 公开岗位页

怎么用

  1. 上传简历：PDF / DOCX / TXT，自动抽岗位、年限、学历、城市、技能，填进左侧画像。文件只在内存解析，不落库。
  2. 搜岗位：关键词 + 城市，选来源。猎聘按城市搜；LinkedIn 用 guest 公开接口；V2EX/电鸭用公开 API。
  3. 看结果：规则分先排，点「AI 精评」再调模型；可打开原帖、导出 Markdown/CSV。
  4. 来源登录：BOSS 需要在「来源登录」里粘贴一次 cookie + 同浏览器 UA；脉脉用公开岗位页，无需登录。cookie 失效会明确报错。
  5. 手动粘贴：任何来源都可以复制 JD 进来，或贴一条公开链接导入。

分数怎么来

规则分 = 技能 45% + 年限 20% + 薪资 15% + 学历 10% + 城市 10%，再扣风险信号（外包、996、年龄限制等，最多扣 30）。 年限或学历硬门槛不过，分数封顶 45–50。AI 分只占最终分 45%，规则分仍占 55%。

来源边界

已接：猎聘、LinkedIn、V2EX 酷工作、电鸭社区、脉脉公开岗位页、Remote OK（英文远程，默认关）。 BOSS 直聘需要登录 cookie：在「来源登录」粘贴一次，UA 要与登录浏览器一致；cookie 失效会返回 code 37。 不硬闯验证码，也不伪造数据。

隐私

画像、简历、JD 只存在这台设备的 localStorage；服务端解析上传文件后即丢弃，不保存正文、不记录 IP，只累计匿名次数。
